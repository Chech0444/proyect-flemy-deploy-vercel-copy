# Modulo Learning

Administra inscripciones, acceso al contenido y trazabilidad del progreso.

## Funcionalidades

- Inscripcion unica por curso.
- Listado de cursos inscritos.
- Vista estructurada del curso.
- Marcado de leccion completada.
- Calculo de progreso por curso y resumen global.

## Ejecucion

Rutas expuestas bajo `api/v1/learning/`.

Depende de `courses` y `users`.
