# Modulo Courses

Gestiona el catalogo, estructura academica y control premium del contenido.

## Funcionalidades

- Catalogo publico.
- CRUD admin de cursos.
- CRUD admin de secciones.
- CRUD admin de lecciones.
- Control de campos obligatorios y orden logico.

## Ejecucion

Rutas expuestas bajo `api/v1/courses/`.

Admin: `http://localhost:8000/admin/courses/`
